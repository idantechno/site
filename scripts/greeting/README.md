# ברכת שנה טובה — סרטון

סרטון ברכה קצר (15 שניות, ללא סאונד) מטעם Portal Studio.

**הרעיון:** סמל המותג הוא צמצם. הסרטון פותח בחשכה עם ניצוץ קורל בודד,
הסמל נבנה סביבו מבחוץ פנימה, ואז נפתח כמו תריס מצלמה — האור שבפנים
מציף את הפריים והופך לברכה. מסתיים על נעילת המותג.

## הפלטים

| קובץ | מידות | שימוש |
|------|-------|-------|
| `public/greetings/shana-tova-5787-square.mp4` | 1080×1080 | פיד, וואטסאפ, פייסבוק |
| `public/greetings/shana-tova-5787-story.mp4`  | 1080×1920 | סטורי, סטטוס, ריל |

H.264 / yuv420p + AAC סטריאו — מתנגן בכל מקום.
הפריים האחרון נעצר על נעילת המותג, כדי שגם התמונה הממוזערת תעבוד.

## הסאונד

מסונתז מאפס ב-`audio.py`, בלי דגימות חיצוניות — **ולכן אין עליו שום
שאלת רישוי, גם בפרסום ממומן.** דרון נמוך בחשכה, נשימה עולה כשהפורטל
נפתח, אקורד פעמונים אחד ברגע האור, וכמה נגיעות בודדות בזמן הברכה.

העוצמה מנורמלת ל-**-16 LUFS** עם שיא אמיתי מתחת ל-1.5- dBTP — היעד
המקובל ברשתות. הנרמול נעשה **בשתי מעברות** עם `linear=true`: נרמול
חד־מעברי הוא דינמי, והוא היה מרים את הפתיחה השקטה ומוחק את ההפרש בין
החושך לרגע האור.

`audio.wav` הוא תוצר ביניים ולא נשמר ב-git — הוא נוצר מחדש בכל רינדור.

### להחליף למוזיקה אחרת

אם בכל זאת רוצים פסקול מספרייה, אין צורך לרנדר מחדש:

```bash
ffmpeg -i public/greetings/shana-tova-5787-square.mp4 -i track.mp3 \
  -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4
```

להוספת נרמול עוצמה: `-af loudnorm=I=-16:TP=-1.5:LRA=11`.

## הקבצים

- `scene.html` — האנימציה עצמה. קנבס אחד, וכל פריים הוא פונקציה טהורה
  של הזמן (`window.__render(t)`) — ולכן הרינדור זהה בכל הרצה.
- `render.mjs` — לוכד את הפריימים ומזרים אותם ל-ffmpeg.
- `heebo-embedded.css` — Heebo מוטמע כ-base64, כדי שהרינדור לא יהיה
  תלוי ברשת ויֵצא זהה בכל פעם.

הסמל מצויר בקוד (שלושה "ורדים" מקוננים — ראו `drawRose`), לפי
הפרופורציות של `public/brand/portal-icon.png`. קובץ ה-PNG עצמו משמש
רק בכרטיס הסיום.

> שימו לב: מבין קבצי המותג ב-`public/brand/`, רק `portal-icon.png` הוא
> PNG עם שקיפות אמיתית. לשאר יש רקע דמקה צרוב בתמונה.

## תצוגה מקדימה בדפדפן

```
scene.html?w=1080&h=1080&play=1
```

## רינדור מחדש

התלויות מותקנות מחוץ לפרויקט (הן לא נחוצות ל-build של האתר):

```bash
npm i --no-save playwright ffmpeg-static
pip install numpy          # לסינתזת הסאונד
node scripts/greeting/render.mjs
```

`render.mjs` מריץ את `audio.py` בעצמו, מנרמל עוצמה וממזג לווידאו.
אם numpy או python3 חסרים — הוא מרנדר בלי סאונד ומדפיס אזהרה.

משתני סביבה אופציונליים: `CHROMIUM_PATH`, `FFMPEG_PATH`.

## שינוי הנוסח או התזמון

כל הטקסטים והתזמונים מרוכזים בראש `scene.html` — האובייקט `T` (ציר הזמן)
והמחרוזות בגוף `render()`. שינוי שנה עברית: חפשו `תשפ״ז`.

התזמונים ב-`audio.py` מסונכרנים ידנית לאותם רגעים — אם משנים את `T`,
צריך להזיז גם את ה-`place(...)` המתאימים.
