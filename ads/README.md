# מודעות למסכים דיגיטליים (DOOH)

## `mall-board/` — פרסומת 6 שניות ללוח בכניסה לקניון

- **פורמט:** 1920×1080, אופקי, 30fps, ללא קול
- **לולאה:** 6.0 שניות בדיוק, עם fade לנייבי בקצוות כך שהחיבור חלק
- **מסר:** סוכן שעונה ללקוחות וקובע להם תורים ביומן
- **CTA:** מספר וואטסאפ `051-522-3921` + QR שפותח שיחה עם ההודעה "היי, ראיתי אתכם בקניון" מוכנה — כך שכל ליד שמגיע מהלוח מזהה את עצמו

### מבנה הזמנים

| שנייה | מה קורה |
|---|---|
| 0.0–0.2 | fade in מנייבי |
| 0.35 | הנייד נכנס מימין |
| 0.5 | הודעת הלקוח נכנסת — "אפשר לקבוע תור למחר?" |
| 0.6 | "סוכן שעונה ללקוחות" |
| 1.6 | "ומנהל לך את היומן," + נקודות "מקליד" |
| 2.6 | תשובת הסוכן נכנסת — באותה דקה בדיוק (זו ההוכחה) |
| 2.7 | "ולא מפספס כלום." בקורל |
| 3.2 | צ'יפ "✓ נוסף ליומן · מחר, 10:00" |
| 3.7–3.9 | הכותרת יוצאת, הלוקאפ נכנס |
| 3.9–5.8 | **פריים סטטי**: לוגו + "כתוב היי" + מספר + QR |
| 5.8–6.0 | fade לנייבי, חזרה ללולאה |

הפריים הסטטי מחזיק ~2 שניות — זה הזמן שלוקח לעובר אורח להוציא טלפון ולסרוק.

## עריכה

הכול בקובץ אחד: `mall-board/index.html`. כל ההנפשות הן keyframes של 6 שניות
באחוזים, כך שהתזמון תמיד מסונכרן ומתחבר בלולאה — כדי להזיז אירוע, משנים אחוז
בלבד. `--T` ב-`:root` מגדיר את אורך הלולאה.

**תקציב רוחב לכותרת:** עמודת הטקסט היא 1136px. שורה ב-`.hl` (118px) מחזיקה
~20 תווים, ושורת ה-`.hl3` (146px) ~15 תווים. טקסט ארוך יותר נשבר לשתי שורות
ושובר את הקצב של שלוש הפעימות — כדאי למדוד לפני שמחליפים נוסח.

ה-QR נוצר מראש ל-`mall-board/qr.svg`. אם המספר או ההודעה משתנים:

```bash
node ads/make-qr.mjs "היי, ראיתי אתכם בקניון"
```

שים לב שכל תו עברי עולה 6 תווים אחרי URL-encoding, כך שהודעה ארוכה מנפחת את
ה-QR ומקטינה את המודולים. ההודעה הנוכחית יוצאת 41×41 מודולים ב-312px, כלומר
~7.6px למודול — נסרק בנוחות מ-2-3 מטר. אם ההודעה מתארכת, צריך להגדיל את `.qr`
באותה מידה.

## תצוגה מקדימה

```bash
node ads/server.mjs
```

ואז `http://localhost:4321/mall-board/`. (או דרך התצורה `ads-preview` ב-`.claude/launch.json`.)

## ייצוא לוידאו

שלב 1 — רינדור פריימים (דורש שהשרת למעלה ו-Chrome מותקן):

```bash
node ads/render.mjs mall-board
```

הפריימים נכתבים ל-`ads/out/mall-board/frame-0000.png`...

שלב 2 — קידוד ל-MP4 (דורש ffmpeg):

```bash
ffmpeg -y -framerate 30 -i ads/out/mall-board/frame-%04d.png -f lavfi -i anullsrc=r=48000:cl=stereo -shortest -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 16 -preset slow -c:a aac -b:a 128k -movflags +faststart ads/out/portal-mall-board-6s.mp4
```

פס הקול השקט נוסף בכוונה — חלק מנגני ה-DOOH דוחים קובץ בלי אודיו.

`ads/out/` לא נכנס ל-git.
